# План миграции — безопасный переход с Tilda

> Цель №1 владельца: переключиться со старого сайта на новый «в один миг», **не просесть** в поиске и рекламе, и чтобы стало только лучше.
> Домен `aerocomfort.es` — на Namecheap (доступ у Димы). Tilda — помесячно, гасим в самом конце.

## 1. Принцип

Тот же домен, то же позиционирование, тот же (или лучше) контент по тем же запросам. Меняется движок и качество, **не меняется** то, за что Google уже любит сайт. Переключение — на уровне DNS, обратимое.

## 2. Подготовка (заранее, не трогая прод)

1. **Доступы**: Search Console (A1), Google Ads (A2), Analytics/GTM (A3), GBP (A4).
2. **Инвентаризация старого сайта**:
   - Полный список URL (Search Console → Pages, + краулинг). Известно: `/`, `/es`, `/thank-you`, страницы офферов(?).
   - Топ-запросы и топ-страницы по кликам/показам за 12 мес — это «что нельзя потерять».
   - Текущие конверсии Google Ads (см. [06](06-seo-aeo.md) §5.1).
3. **Бенчмарк «до»**: клики/показы/позиции, конверсии/мес, доля рекламы vs органика (B2).
4. **Карта редиректов** `old → new` (см. §4).
5. **Перенос DNS-зоны в Cloudflare заранее**: в Cloudflare добавить сайт `aerocomfort.es`, скопировать существующие записи (важно — почта/MX, проверка доменов!), в Namecheap сменить nameservers на Cloudflare. **На работу Tilda это не влияет** (записи указывают туда же). Это разделяет «перенос DNS» и «переключение сайта» на два независимых шага → меньше риска. Заранее снизить TTL.

> ⚠️ Перед сменой nameservers выписать ВСЕ текущие записи (A/CNAME/MX/TXT/SPF/DKIM), чтобы не уронить почту и верификации. Делаем аккуратно.

## 3. Готовность нового сайта (Definition of Ready для запуска)
- [ ] Все страницы Фазы 1 готовы на EN и ES, вычитаны.
- [ ] Контент покрывает ключевые темы/запросы старого сайта (паритет или лучше).
- [ ] Формы шлют лиды (email + Sheets), телефон валидируется, спам-защита.
- [ ] Все конверсии навешены и проверены в Tag Assistant.
- [ ] hreflang, canonical, sitemap, robots, schema — на месте.
- [ ] Редиректы настроены и протестированы.
- [ ] Lighthouse/CWV в зелёной зоне (моб).
- [ ] `info@aerocomfort.es` (Email Routing) работает, если переходим на доменную почту (G4).
- [ ] Юридические страницы заполнены (реквизиты C3).
- [ ] QA на реальных устройствах (моб/планшет/десктоп), кросс-браузерно.

## 4. Карта редиректов (301)

Точную таблицу заполним из инвентаризации. Каркас:

| Старый URL (Tilda) | Новый URL | Тип |
|---|---|---|
| `/` | `/` | 200 (тот же) |
| `/es` | `/es/` | 301 (нормализация слеша) |
| `/thank-you` | `/thank-you` | 200 (сохранить — конверсия!) |
| страницы офферов (если есть отд. URL) | `/offers` или конкретные | 301 |
| прочие найденные URL | соответствующие новые | 301 |
| несуществующее старое | ближайшее релевантное (не на главную «оптом») | 301 |

Редиректы — через Cloudflare (`_redirects`/Worker/Bulk Redirects). 301 (постоянный), 1:1 по смыслу, без цепочек.

## 5. Переключение (cutover)

Поскольку DNS уже в Cloudflare, само переключение = направить `aerocomfort.es` на новый Worker (custom domain), снять `noindex`, включить редиректы. Минуты, обратимо.

1. Финальный деплой `main`, прогон чек-листа.
2. Снять `noindex`/`robots` запрет с прод-домена.
3. Привязать `aerocomfort.es` (+ `www`) к Worker; включить карту редиректов.
4. Проверить вживую: главные URL, редиректы, формы→лид, конверсии стреляют, hreflang, почта.
5. **Откат** при проблеме: вернуть DNS/route на Tilda (因 заранее знаем записи) — минуты.

## 6. После запуска (первые часы/дни)
- Search Console: подтвердить домен (если ещё), **отправить новый sitemap**, запросить индексацию ключевых страниц, проверить отчёт Coverage/redirects.
- Проверить, что объявления Google Ads ведут на живые URL (иначе — стоп-показы/штраф качества).
- Прогнать реальную заявку с телефона → дошёл ли лид на email/Sheets, сработала ли конверсия.
- Тест почты `info@aerocomfort.es` (приём).

## 7. Мониторинг (4–8 недель) и вывод Tilda
- Еженедельно: позиции по топ-запросам, клики/показы, ошибки индексации, конверсии vs бенчмарк.
- Небольшая просадка в первые 1–2 недели (Google переобходит) — норма; следим за трендом.
- Когда метрики стабильны/растут и конверсии подтверждены → **отключаем подписку Tilda**.
- Зафиксировать «после» и сравнить с «до» — отчёт владельцу.

## 8. Что снижает риск (резюме)
- Тот же домен, паритет контента, корректные 301, hreflang.
- DNS-перенос и cutover разнесены; низкий TTL; знаем старые записи → быстрый откат.
- Конверсии воспроизведены и проверены ДО переключения.
- Tilda живёт параллельно до подтверждения успеха.
