## 3. Аудитория

- Мужчины 40+, экспаты и местные: Англия, Ирландия, Испания, Германия и др.
- Язык в основном английский, часть — испанский.
- **Болевая точка:** оставляют телефоны в странном/неверном формате (испанские номера и номера своих стран). Текущий селектор кода страны + JS-валидация не спасают. Нужна надёжная валидация и UX, направляющий к корректному номеру.

## 4. Цели нового сайта

1. **Безопасный переход:** не просесть в поиске и рекламе; переключение домена «в один миг»; показатели должны только вырасти.
2. **Натив и скорость:** статический сайт, идеальный Lighthouse по всем пунктам.
3. **SEO + AEO/GEO:** видимость и для поисковиков, и для LLM-агентов — структурированные данные, факты, блог/спец-страницы, читабельная структура.
4. **Красивый профессиональный дизайн**, не «типичный AI-эстетик».
5. **Поддерживаемость промптами:** любые будущие правки — через AI-промпты; в корне проекта — правила/система для консистентности.
6. **На выходе** — инструкция по уходу за сайтом.

## 6. Дизайн

### Mobile-first (обязательно)
Сайт обязан быть отличным на мобильных: аудитория 40+ приходит с рекламы преимущественно со смартфонов. Крупные тач-таргеты, читабельные размеры шрифта, липкая нижняя панель действий (позвонить / WhatsApp) — рассмотреть. Lighthouse mobile — приоритетная метрика.

### Лого
- Белая геометрическая монограмма «AC» + надпись AERO/COMFORT; фирменный тёмно-синий фон (примерно #2B4170–#2D4A8A — уточнить пипеткой по скриншоту). Этот синий — якорный цвет бренд-палитры.
- Оригинал PNG: `assets/brand/aerocomfort-logo.png` (811×718, белый на прозрачном — версия для тёмных подложек; источник: Tilda CDN).
- Для светлых фонов сгенерим синюю версию перекраской альфа-маски; при желании позже перерисуем в SVG один в один (формы простые).

### Виджет отзывов Elfsight (по скриншоту) — что воспроизводим
- Шапка: лого Google, «Excellent on Google», рейтинг 5.0, звёзды, счётчик (160), CTA-кнопка «Review us on Google».
- Карусель карточек: аватар, имя, дата («1 day ago on Google»), 5 звёзд, текст, «Read more», стрелки/точки навигации.
- **Решение (2026-06-12): оставляем Elfsight** — владельца полностью устраивает. Виджет встраиваем на новый сайт как есть (скрипт грузим лениво, чтобы не ронять Lighthouse). Свой статический вариант (рейтинг/счётчик через Places API + курируемые карточки) — записан как возможная оптимизация на будущее.

- Лого существующее, не меняем (не идеальное, но бренд).
- Цвета: синий/белый + яркий акцент (приятный красный) для CTA и офферов; CTA и офферы выделять смело.
- WhatsApp — «герой», должен находиться мгновенно.
- Паттерны — с учётом аудитории 40+: крупно, понятно, без модных загадок.
- Стиль текстов: один тон везде, продаём услуги, без воды и перебора.
- Референсы: https://mallorcaairconditioning.com/ (чистый дизайн, чат-виджет), https://climatop.es/ (некрасиво, но популярны — изучить, что у них работает).
