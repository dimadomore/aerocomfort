# Контент и ассеты — Aerocomfort

> Подход к текстам + **точные спецификации фото/иллюстраций/анимаций** по секциям.
> Сейчас в вёрстке оставляем «пространство» (плейсхолдеры с верными пропорциями), ассеты собираем в отдельной фазе.

## 1. Подход к контенту

- **Двуязычно, парно** (EN основной / ES). Каждый текстовый блок существует в обоих языках; чек «обе версии» в Definition of Done.
- **Тон**: прямой, экспертный, дружелюбный; выгода + доказательство; без «воды» (см. [04 §9](04-design-system.md)).
- **Источник правды** — data/i18n-файлы (см. [05 §4](05-information-architecture.md)). Тексты — не в разметке, а в контенте → правки промптом.
- **Плейсхолдеры**: где ждём фактуру Джона, в тексте стоит `‹PLACEHOLDER: …›` — видно, что заполнить (числа, сертификаты, цены, реквизиты).
- **SEO/AEO-копирайт**: естественные ключи («air conditioning installation Torrevieja»), факты, прямые ответы в FAQ.

## 2. Спецификация ассетов

Общие правила: формат **AVIF + WebP** (фолбэк JPG) через Astro `<Image>`; адаптивный `srcset`; lazy-load (кроме LCP-героя — он `eager`/preload); осмысленный `alt` (EN/ES); цветокор в прохладной гамме (синие/нейтральные), тёплый свет на «человеческих» кадрах. Именование: `kebab-case`, англ., по смыслу (`hero-install-torrevieja.avif`). Резерв размеров в вёрстке → ноль CLS.

Легенда приоритета: 🔴 критично для запуска · 🟡 желательно · 🟢 позже.

### 2.1 Hero (Home) 🔴
- **Тип**: реальное фото. Мастер (Джон) аккуратно устанавливает/обслуживает настенный сплит в светлом средиземноморском интерьере ИЛИ чистый наружный блок на фоне испанской виллы/неба.
- **Настроение**: профессионально, чисто, прохладно, дневной свет. Не сток, не 3D.
- **Кадр**: горизонталь, есть «воздух» слева/справа под наложение текста; объект смещён вправо (текст слева).
- **Соотношение/размер**: ~16:9 и ~4:5 (моб-кроп); ≥2400px по ширине; делаем art-direction (разные кропы моб/деск).
- **Fallback при отсутствии фото мастера**: качественный кадр аккуратной установки сплита крупным планом (руки в работе) — без узнаваемых лиц-стоков.
- **Альт-идея декора**: тонкая SVG-линия «потока прохладного воздуха» от блока (в стиле логотипа), едва заметная.

### 2.2 TrustBar 🔴
- Без фото. Числовые плашки + линейные иконки (опыт/установки/рейтинг/зоны). Анимация count-up (см. §3).

### 2.3 Карточки услуг (×4) 🔴
- **Тип**: линейные иконки в стиле логотипа (установка/ремонт/обслуживание/чистка) — единый набор, stroke ~1.75px, цвет `--navy`/`--blue`.
- Опционально 🟡 маленькое фото-превью реальной работы на каждую услугу.

### 2.4 «Почему мы» / доверие (Home, About) 🔴
- **Тип**: фото Джона за работой — лицо/руки, спокойная уверенность, форма/инструмент с лого если есть (F2/F3).
- **Кадр**: вертикаль или 4:5; реальный объект, не студия.
- Это сильнейший конверсионный ассет для 40+ — приоритет получить настоящее фото.

### 2.5 Галерея работ (before/after) 🔴
- **Тип**: реальные фото объектов. Идеально — **пары «до/после»** (старый/грязный блок → новый/чистый; пустая стена → аккуратный монтаж).
- **Кадр**: консистентные ракурсы в паре; горизонталь и вертикаль ок; ≥1600px.
- **Объём**: 8–16 сильных кадров для старта (на Tilda 40+ — взять лучшие оригиналы, F1).
- **Подписи**: тип работы + район («Daikin install · Orihuela Costa») — польза для локального SEO/AEO.

### 2.6 Офферы (×5) 🔴
- **Тип**: чистые фото/рендеры конкретных моделей кондиционеров (Giatsu AROMA 2E, LG, Panasonic, Daikin, Mitsubishi) на белом/прозрачном — каталожный стиль.
- **Кадр**: фронтально, одинаковый ракурс/паддинг для всех 5 (консистентная сетка); PNG/AVIF с прозрачностью; ~1:1 или 4:3.
- **Источник**: пресс-кит производителей / дилерские материалы (легально использовать?) — проверить (D2). Иначе — единые фото своих установок этих моделей.

### 2.7 Логотипы брендов 🔴
- **Тип**: официальные SVG-логотипы брендов (моно/цвет), выровненные по оптическому размеру, в ряд. Грейскейл → цвет на hover (сдержанно).
- Проверить право на использование марок.

### 2.8 Карта зон 🔴
- **Тип**: open-source карта (MapLibre + бесплатные тайлы) ИЛИ **стилизованный SVG-контур** Costa Blanca с маркерами зон в бренд-цветах (легче, без внешнего JS — предпочтительно).
- Маркеры/подсветка обслуживаемых районов; клик → страница зоны (Фаза 2).

### 2.9 About — портрет 🔴/🟡
- **Тип**: портрет Джона (дружелюбный, профессиональный, дневной свет, нейтральный фон/объект) + 1–2 «в деле».
- **Кадр**: вертикаль 4:5; ≥1600px.

### 2.10 OG-картинки (соц-превью) 🔴
- **Тип**: генерируемый бренд-шаблон (лого + заголовок страницы + фон навы/фото). 1200×630.
- Важно для WhatsApp-репостов и соцсетей. Делаем шаблон, авто-подстановка заголовка.

### 2.11 Favicon / app icons 🔴
- Из монограммы лого: `favicon.svg`, `.ico`, 180×180 apple-touch, `192/512` maskable, `theme-color` (navy).

### 2.12 Блог (Фаза 3) 🟢
- Обложка на статью (реальное фото с объекта из Telegram-пайплайна), 16:9 ≥1600px; alt обязательно.

## 3. Анимации (точные, сдержанные)

Все уважают `prefers-reduced-motion: reduce` (выключаются). Длительности 150–250ms, ease-out.
- **Hero airflow** 🟡: тонкие SVG-линии «прохладного воздуха» с медленным плавным движением (loop, низкая амплитуда, ~8–12s). Декор, не отвлекает.
- **Count-up TrustBar** 🔴: числа набегают 0→значение при попадании в вьюпорт (один раз).
- **Reveal секций** 🔴: мягкий fade + небольшой translateY (8–16px) при скролле.
- **Hover-состояния** 🔴: кнопки/карточки — лёгкий подъём тени + сдвиг 1–2px.
- **Chat-launcher tooltip** 🔴: однократный деликатный «пульс»/выезд приветствия через ~2–3s после загрузки.
- **Sticky mobile bar** 🔴: плавный slide-in снизу после скролла за hero.
- **Карусели** (галерея/Elfsight) 🔴: плавная прокрутка, свайп на тач.
- ❌ Без: параллакса, скролл-джекинга, автоплей-видео со звуком, бесконечных «дышащих» градиентов.
